# Documentazione @ares/coding-js

## Scopo

Toolkit di analisi JavaScript: parsing in AST, estrazione funzioni, costruzione del Control Flow Graph (CFG), esecuzione instrumentata e resa Mermaid.

## Obiettivo (roadmap)

Questo modulo è la base naturale per una linea di evoluzione più ampia:

- analizzare JavaScript ed esporre primitive AST/CFG stabili;
- abilitare in futuro la traduzione di codice/applicazioni tra linguaggi tramite trasformazioni AST (code-to-code / app-to-app).

## Installazione

```bash
yarn add @ares/coding-js
```
