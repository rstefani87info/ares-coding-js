# @ares/coding-js Documentation

## Purpose

JavaScript code analysis toolkit: parse source code into AST, extract functions, build a Control Flow Graph (CFG), run instrumented executions and render a Mermaid representation.

## Goal (roadmap)

This module is a natural foundation for a broader track:

- analyze JavaScript and expose stable AST/CFG primitives;
- evolve towards multi-language code translation by leveraging AST transforms (future: code-to-code / app-to-app transformations).

## Installation

```bash
yarn add @ares/coding-js
```
